## YouTube Clone

A responsive YouTube clone web application that mimics the core UI and functionality of the popular video-sharing platform. Built with HTML, CSS, and JavaScript.

## Features

Dynamic Navigation: Fully functional navigation menu similar to YouTube.

Video Playback: Embedded videos with playback controls.

Responsive Design: Optimized for various screen sizes.

Interactive Elements: Buttons and links that simulate real YouTube functionality.


## Tech Stack

Frontend: HTML, CSS, JavaScript

Assets: Custom images and icons


##Folder Structure

YOUTUBE-CLONE-main/
├── index.html          # Main HTML file
├── styles.css          # Styling for the application
├── script.js           # JavaScript logic
├── images/             # Assets including icons, thumbnails, and videos
└── demo.mp4            # Demonstration video


## Installation

Clone the repository:

git clone [<repository-url>](https://github.com/yashwanthmk11/YOUTUBE-CLONE.git)

Navigate to the project directory:

cd YOUTUBE-CLONE-main

Open index.html in your web browser:

open index.html
